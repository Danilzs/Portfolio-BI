# Dashboard de Vendas - Treinamento BI

Este projeto consiste em uma análise de dados de vendas, utilizando bases de dados reais para gerar insights através de dashboards interativos.

## 🗂 Estrutura dos Dados

O projeto utiliza duas bases de dados principais localizadas na pasta `BaseDados`:

### 1. `BaseVendasCompleta.xlsx`
Contém o registro detalhado das transações comerciais.
* **Conteúdo:** Data da venda, ID do produto, ID do cliente, quantidade, valor unitário, loja, vendedor.
* **Objetivo:** Permitir análises de tendência temporal, performance por loja e faturamento total.

### 2. `CadastroProdutos.xlsx`
Tabela dimensão com detalhes dos produtos.
* **Conteúdo:** ID do produto, nome, categoria, custo.
* **Objetivo:** Enriquecer a base de vendas com informações descritivas dos produtos para segmentação por categoria.

## 🛠 Tecnologias Utilizadas

* **Excel:** Para armazenamento e pré-processamento dos dados.
* **Power BI / Ferramenta BI:** Para criação do dashboard interativo.

## 🚀 Como Utilizar

1. Clone este repositório.
2. Acesse a pasta `BaseDados` para verificar os arquivos originais.
3. Abra a imagem na raiz para visualizar o resultado final da análise.
4. Baixe o arquivo Treinamento-BI.pbix e abra-o no Power BI Desktop.
